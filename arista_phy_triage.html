PHYSICAL LAYER TRIAGE & ROOT CAUSE ANALYSIS

Arista EOS Layer 1 & Optics Runbook

Field diagnostic runbook for isolating physical network faults on Arista EOS switches. Designed to rapidly distinguish between optic failures, dirty fiber endpoints, transceivers, FEC lane mismatches, and Far-End NIC problems.

Physical Triage Rule: Replace Et49/1 or Ethernet49/1 with your target port breakout. Always inspect show interfaces counters errors and capture DDM RX power prior to issuing counter clears or port resets.
1. Fault Isolation Matrix 2. DDM & Optics Power 3. Errors, CRC & Flaps 4. PHY, FEC & Auto-Neg 5. Far-End & Cable Map 6. Port Actions & Recovery

1. Fault Isolation Decision Matrix

Match observable symptoms directly to the physical component causing the failure.

Symptom / CLI Output Probable Root Cause Actionable Next Step
RX Power < -12 dBm (or -30 dBm) Dirty fiber, broken strand, unseated optic, or far-end TX disabled. Inspect patch cable with VFL/scope; clean LC/MPO end-faces with click cleaner; verify far-end TX power.
FCS / Alignment / CRC Errors Degraded optical signal, marginal patch cord, dirty connector, or bend radius violation. Check DDM RX power; inspect clean fiber; reseat transceiver; if errors persist, swap patch cord.
Link Flaps (>5 in short window) Marginal optical budget, failing laser diode, or loose transceiver latch. Check show interfaces link-flaps; replace transceiver module; verify cable strain relief.
Port NotConnect / Admin UP Far-end server down, mismatched speed/FEC, or wrong breakout profile. Check breakout configuration (e.g. 4x25G vs 100G); verify far-end NIC link state.
FEC Uncorrectable Words > 0 Signal-to-noise ratio (SNR) failure on electrical/optical lanes. Verify matching FEC modes on both ends (rs vs fc vs disabled). Reseat optic.

2. DDM Optical Power & Transceiver Telemetry

Inspect light levels, laser bias currents, and module EEPROM serial numbers.

Full Transceiver DDM Diagnostic

show interfaces ethernet 49/1 transceiver detail

Displays live TX/RX power (dBm & mW), laser bias current, temperature, and alarm/warning threshold limits.

Summary of All Optical Power Levels

show interfaces transceiver | grep -E "(Port|Eth49)"

Quick scan across lanes to spot low RX/TX levels (< -10 dBm indicates degraded light; -30 dBm is dark fiber).

Transceiver Hardware & Serial Number

show inventory | grep -i "Ethernet49/1"

Returns optic part number, vendor name, revision, and serial number for RMA ticketing.

Watch Optical Power Real-Time (3s Refresh)

watch interval 3 show interfaces ethernet 49/1 transceiver detail

Keeps a live loop running while physically wiggling cables or cleaning fiber to observe light changes.

3. Layer 1 Errors, CRC & Link Flap Analysis

Isolate whether errors are occurring on physical media (CRC/FCS) or internal MAC drops.

Interface Error Counters Overview

show interfaces ethernet 49/1 counters errors

Displays FCS errors, alignment errors, runts, giants, and symbol error counts on the physical port.

Non-Zero Error Filter (All Switch Ports)

show interfaces counters errors | nz

Shows only interfaces currently experiencing active FCS, CRC, or collision errors across the entire switch.

Link Flap Detection & Historical Timestamps

show interfaces link-flaps | grep -E "(Interface|Et49/1)"

Identifies how many times physical link state dropped and the timestamp of the last transition.

Check Hardware PHY Error Counters

show hardware mac interface ethernet 49/1 counters

Dumps low-level ASIC/MAC layer statistics to differentiate physical cable errors from switch ASIC drops.

Clear Interface Counters for Retest

clear counters ethernet 49/1

Resets error and packet counters to zero. Always run this immediately after swapping or cleaning fiber to test clean.

Inspect Tail System Syslog for Flaps

show logging | grep -i "Ethernet49/1" | tail 40

Pinpoints state transitions (LINK-5-CHANGED, LINEPROTO-5-UPDOWN, optical threshold traps).

4. Speed, Auto-Negotiation & FEC (Forward Error Correction)

Validate that line encoding, FEC algorithms, and lane breakout configurations match.

Check Forward Error Correction (FEC) Status

show interfaces ethernet 49/1 phy

Verifies operational and configured FEC (Base-R, Reed-Solomon / RS-FEC, or Disabled) and lane training.

FEC Correctable vs Uncorrectable Words

show interfaces ethernet 49/1 counters fec-errors

High uncorrectable words indicate dirty fiber or bad optics. High correctable with zero uncorrectable is normal.

Interface Capabilities & Supported Speeds

show interfaces ethernet 49/1 capabilities

Displays what speeds, duplexes, breakout combinations, and media types the port and installed optic support.

Speed & Duplex Physical Status

show interfaces ethernet 49/1 status

Displays Line Protocol, Operating Speed, Duplex, Transceiver Media Type (e.g. 100GBASE-SR4), and VLAN.

5. Far-End Discovery & Cable Mapping (LLDP)

Validate whether the connected far-end device matches the engineering design plan.

Detailed LLDP Far-End Neighbor Audit

show lldp neighbors ethernet 49/1 detail

Shows far-end System Name, Management IPv4/IPv6, Remote Port ID (e.g. NIC inb_mnic0 or eth0), and MTU.

Global LLDP Neighbor Table

show lldp neighbors

Quick table mapping every physical switch port to its connected host or peer switch.

6. Controlled Recovery & Port Bouncing

Least-disruptive actions to force optical link retrain, reset transceiver logic, or force FEC settings.

Controlled Port Bounce (Laser Retrain)

configure
interface ethernet 49/1
shutdown
! wait 10 seconds for far-end detection
no shutdown
end

Forces laser re-initialization and resets the SerDes lane training state machine.

Force FEC Mode to Reed-Solomon (RS-FEC)

configure
interface ethernet 49/1
error-correction encoding reed-solomon
end

Enforces RS-FEC on 100G/200G interfaces when auto-negotiation fails to agree on an FEC algorithm.

Disable FEC (Direct Attached Copper / Low Latency)

configure
interface ethernet 49/1
error-correction encoding none
end

Disables FEC if connected to a legacy NIC or test fixture that does not support forward error correction.

Hard Breakout Reconfiguration (e.g., 4x25G Breakout)

configure
interface ethernet 49/1
speed forced 25gfull
end

Forces lane speed when connecting 100G QSFP28 ports split into 4x25G links to SmartNICs.

No Arista physical layer commands match this filter.
