NETWORK & FABRIC TRIAGE

Switch & Optical Triage Reference

Field cheat sheet for Bastion connectivity, Mellanox MST/mlxlink diagnostics, NVIDIA Quantum InfiniBand link verification, and Arista EOS leaf/spine validation.

Engineering Reminder: In Mellanox/NVIDIA diagnostics, enter fae mode prior to running low-level BER and DDM flags. Clear counters only after baseline error rates have been recorded in the shift handover or incident ticket.
Bastion Access Mellanox mlxlink NVIDIA Quantum IB Arista EOS Fabric Deep Dive

1. Bastion & Switch SSH Access

Use when direct switch access is blocked or PKCS11 tokens cause authentication failure.

Standard Switch SSH

ssh root@<switch-ip-or-hostname>

Standard administrative switch login.

Bastion Bypass SSH (No PKCS11 / Token Bypass)

ssh -o IdentitiesOnly=yes -o PKCS11Provider=none abmazlan@<switch-ip>

Run on Bastion host when hardware tokens or agent auth locks out direct SSH.

Port Notation & Engineering Rule: Parameters such as -p 1/1, -p 2/1, or 49/1 represent physical cage/port and split-lane breakout numbers. Enter fae mode prior to executing low-level BER and DDM queries. Record baseline counters before clearing.

2. Mellanox MST & mlxlink Triage

Low-level ASIC, transceiver DDM, and BER monitoring via the MST subsystem. (Note: -p <port/lane> specifies the physical port/split, e.g., 1/1 or 2/1).

Enter FAE Diagnostic Mode

fae

Required prerequisite on NVIDIA/Mellanox switches before running advanced cable/DDM flags.

DDM Optical Levels & BER Monitor (Port 1/1)

mlxlink -d /dev/mst/mt54002_pciconf0 --cable --ddm -p 1/1 -c

Queries physical port 1/1 for live optical power (DDM) and bit error rate (show_ber_monitor).

DDM with Extended Module Details (Port 2/1)

mlxlink -d /dev/mst/mt54002_pciconf0 --cable --ddm -p 2/1 -c -m

Queries physical port 2/1 with full module EEPROM details and per-lane power.

Eye Diagram & Module Telemetry (Port 1/2)

mlxlink -d /dev/mst/mt54002_pciconf0 -p 1/2 -e -m -c

Queries physical port 1/2 for eye opening diagnostics (-e), module info (-m), and status (-c).

Clear Error Counters (Port 1/1)

mlxlink -d /dev/mst/mt54002_pciconf0 -p 1/1 --pc

Clears hardware error counters specifically on port 1/1. Enter fae first.

List Local MST Devices

mst status -v

Lists available PCI endpoints if targeting a device path other than mt54002_pciconf0.

3. NVIDIA Quantum InfiniBand CLI

Switch-level fabric verification, port status, and real-time optical power polling.

Show All IB Transceivers

show interfaces ib transceiver

Global readout of all connected QSFP/OSFP transceivers and cables.

I2C Optical Bus Check (Hang / Bug Triage)

show interfaces ib transceiver | include I2c

Checks for stuck I2C busses causing missing transceivers or telemetry drops.

Real-Time Optical Power Polling (TX/RX Loop)

show interfaces ib 1/6/1 transceiver diagnostics | watch interval 1

1-second refresh on optical levels. Essential when reseating or cleaning fiber.

Single Port Link Diagnostics

show interfaces ib 1/28/1 link-diagnostics

Checks symbol errors, recovery sequences, and physical lane training state.

Port Physical & Logical Status

show interfaces ib 1/22/1 status

Displays admin state, physical link state, MTU, and negotiated speed (NDR/HDR).

Port Hardware Error Counters

show interfaces ib 1/17/1 counters

Inspects packet discards, symbol errors, and link buffer overruns.

4. Arista EOS Ethernet Triage

Ethernet fabric, CRC error detection, transceiver DOM values, and STP state checks.

Interface Details, Errors & CRC

show interfaces ethernet 49/1

Displays line protocol state, input/output CRC errors, runt packets, and bandwidth.

Digital Optical Monitoring (DOM / DDM)

show interfaces ethernet 49/1 transceiver detail

Inspects TX bias current, TX power, RX optical power, and alarm/warning thresholds.

Global Transceiver Presence Summary

show interface transceiver

Table of all inserted optics, serial numbers, vendors, and wavelengths.

Spanning Tree Blocked Ports

show spanning-tree

Verifies whether STP has placed a suspected down link into blocking or discarding mode.

Recent Switch Syslog & Link Flaps

show logging | tail 50

Inspects system event log for port flaps, optical power threshold traps, or STP shifts.

Clear Ethernet Counters

clear counters ethernet 49/1

Resets packet and CRC error counters to zero for clean loop verification.

5. Advanced Fabric Helpers (LLDP, Optics & Port Bounce)

High-value utility commands for neighbor discovery and controlled bounce sequences.

LLDP Neighbor Verification (Arista EOS)

show lldp neighbors ethernet 49/1 detail

Verifies the far-end hostname, management IP, and peer port connected to the cable.

LACP Port-Channel Aggregation State (Arista EOS)

show lacp interface ethernet 49/1

Verifies actor/partner sync and determines if bundle negotiation is failing.

InfiniBand IBnetdiscover (Host/Subnet Manager)

ibnetdiscover -p | grep -E "<switch-guid-or-lid>"

Maps fabric topology and peer GUIDs across the high-speed IB network.

Controlled Port Bounce (Arista EOS)

configure
interface ethernet 49/1
shutdown
! wait 10s
no shutdown
end

Forces laser retrain and link renegotiation on sticky optical ports.
