GPUv6 PCIe Cable Validation Guide

Step-by-step verification procedure for GPUv6 PCIe link training, cable mapping, and switch bus verification across Head Node and Tail Node.

Required Tools: HOPS CLI, Bastion Host, and ILOM SP Diag Shell

Primary Objective: Ensure all 8 OAM bus endpoints (0D, 5D, A7, 26, F4, 75, 8E, DC) train successfully and match switch line outputs.

1. Target IP Discovery 2. Head Node Trigger 3. Tail Node PCIe Status 4. Bus Verification Matrix

Phase 1: Initial Discovery (HOPS CLI)

Check host state and gather target ILOM IP address before connecting through the bastion tool.

Step 1

Gather Network & State Information

state
network_info
# Extract the target ILOM IP, then connect via the Bastion tool

Phase 2: Cable Check Trigger (Head Node & Tail Node)

Run flow triggers on both nodes; observe results on the head node.

Step 2

Initiate Cable Validation Flow

set -script /SP system_contact=flow=cable_check_flow
load -source https://hops-data-service.svc.ad1.ap-kulai-1:11001/firmware/GPUv6_Update_AMD_100_1_5_6.pkg.signed -nowait -script

Phase 3: Bus Extraction (Tail Node)

Collect PCIe status output from the diagnostic shell and extract downstream bus identifiers.

Step 3.1

Dump Diagnostics to File

start /SP/diag/shell -script
hwdiag pci status all

Save the entire command output to a local working file named pci.txt.

Step 3.2

Extract OAM Bus Identifiers

grep -A1 OAM pci.txt | grep BUSES | sed -E 's/.*\(([0-9A-F]+<->[0-9A-F]+)\).*/\1/' | awk -F '>' '{print $2}'

The regex pipeline filters down to the 8 expected bus targets:

0D
5D
A7
26
F4
75
8E
DC

Phase 4: Output Verification Guide

Confirm all 8 extracted hex codes correspond to the downstream bus (line 3) for each PCIe switch block.
