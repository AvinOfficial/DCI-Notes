Quick checks

Start here to establish health, faults, firmware, and power state.

System health

show /System -t health

Overall system health state.

Open problems

show /System/Open_Problems

Current host problems reported by ILOM.

Fault summary

show faulty

ILOM fault information.

Event log

show /SP/logs/event/list

Service-processor event log.

Firmware versions

show -l all -d properties /System/Firmware

Firmware details in one view.

Host power state

show /SYS power_state

Whether the host is on or off.

ILOM / SP version

version /SP

Installed ILOM firmware version.

Service processor clock

show /SP/clock

Checks ILOM time and synchronization state.

Fault investigation & clearing

Enter the fault-management shell before running fmadm or fmdump.

Open fault-management shell

start -script /SP/faultmgmt/shell

Confirm when prompted.

All FMA faults

fmadm faulty -a

Includes faults outside the default view.

Detailed fault events

fmdump -eVi

Raw ereports for investigation.

Clear a specific fault

fmadm repair <device-path>

Preferred method; example path: /SYS/MB.

Mark replaced hardware

fmadm replace <device-path>

Use after replacement if state does not refresh.

Clear all FMA faults

fmadm repair allfaults

Only after confirming every issue is resolved.

Diagnostic shell

Use when normal ILOM fault reporting does not identify the issue.

Enter diagnostic shell

start -script /SP/diag/shell

Confirm when prompted; use exit to return.

System inventory

hwdiag system inventory

System component inventory.

System thermal state

hwdiag system thermal

Temperatures, fan speeds, and power together.

NVMe information

hwdiag io nvme_info

NVMe details and faults.

NVMe test

hwdiag io nvme_test

Tests NVMe drives, controller cards, and cables.

PCI status

hwdiag pci status all

PCI target status for all devices.

I²C connectivity test

hwdiag i2c test all

Tests all I²C devices.

Host boot progress

hwdiag system port80

Host boot progress code.

Power & service control

These commands affect availability. Confirm the correct host and approval first.

Power on host

start /SYS

Starts the host and operating system.

Graceful host shutdown

stop /SYS

Shuts down the OS and powers off the host.

Force host shutdown

stop /SYS -f

Use only when normal shutdown is unresponsive.

Restart host

reset /SYS

Immediately restarts the host.

Cold / deep power cycle

stop /SYS -f

Wait for show /SYS power_state = Off, then run start /SYS.

Restart service processor

reset /SP

Restarts ILOM/SP and disconnects the session.

Locator LED on

set /SYS/LOCATE value=Fast_blink

Turns on front and rear locator LEDs.

Locator LED off

set /SYS/LOCATE value=off

Turns off locator LEDs.

Full diagnostic snapshot

A full snapshot can reboot the host. Obtain approval when allocated.

Set full dataset

ssh -l <guid> <ilom-ip> set /SP/diag/snapshot dataset=full

Includes all available outputs and logs.

Generate snapshot archive

ssh -l <guid> <ilom-ip> set -script /SP/diag/snapshot dump_uri=console > <serial>.zip

Wait up to 10 minutes for the archive.

Verify snapshot

ssh -l <guid> <ilom-ip> show /SP/diag/snapshot

Checks snapshot status.

Return to normal dataset

ssh -l <guid> <ilom-ip> set /SP/diag/snapshot dataset=normal

Run after collection is complete.
