Quick checks

Start here to establish health, faults, firmware, and power state.

System health

show /System -t health

Overall system health state.

Open problems

show /System/Open_Problems

Current host problems reported by ILOM.

Fault summary

show faulty

ILOM fault information.

Event log

show /SP/logs/event/list

Service-processor event log.

Firmware versions

show -l all -d properties /System/Firmware

Firmware details in one view.

Host power state

show /SYS power_state

Whether the host is on or off.

ILOM / SP version

version /SP

Installed ILOM firmware version.

Service processor clock

show /SP/clock

Checks ILOM time and synchronization state.

GPU v6 / E6-IS operational checks

Run hardware commands from diag>. On a GPU system, use the tail-node SP for drive and platform checks unless the procedure explicitly says otherwise.

Enter diagnostic shell

start -script /SP/diag/shell

Required before running hwdiag commands.

NVMe inventory and status

hwdiag io nvme_info

Confirm every expected drive serial is present and no NVMe fault is reported.

Fabric-link validation

hwdiag system fabric test all

Use after confirming the correct head/tail-node cable-check flow is running.

I²C device validation

hwdiag i2c test all

Capture the failed device path, chip, and bus/mux address for hardware escalation.

PCIe status

hwdiag pci status all

Use to validate PCIe device presence and negotiated link state after a reseat.

SP recovery verification

reset /SP

Use only with approval. Reconnect after the SP restarts, then verify health, event log, and reachability for five minutes.

Fault investigation & clearing

Enter the fault-management shell before running fmadm or fmdump.

Open fault-management shell

start -script /SP/faultmgmt/shell

Confirm when prompted.

All FMA faults

fmadm faulty -a

Includes faults outside the default view.

Detailed fault events

fmdump -eVi

Raw ereports for investigation.

Clear a specific fault

fmadm repair <device-path>

Preferred method; example path: /SYS/MB.

Mark replaced hardware

fmadm replace <device-path>

Use after replacement if state does not refresh.

Clear all FMA faults

fmadm repair allfaults

Only after confirming every issue is resolved.

Diagnostics & Diag Shell

Enter the diagnostic shell (start /SP/diag/shell) when standard ILOM reporting does not isolate the issue.

Enter diagnostic shell

start -script /SP/diag/shell

X7/X8/X9/X10 targets; on older X4-X6 run set SESSION mode=restricted.

System inventory

hwdiag system inventory

Low-level chassis component inventory.

System thermal state

hwdiag system thermal

Temperatures, fan RPMs, and power levels together.

Host boot progress (Port 80)

hwdiag system port80

Displays current or historical host POST boot codes.

NVMe information

hwdiag io nvme_info

NVMe controller details, lane speed, and drive faults.

NVMe test

hwdiag io nvme_test

Tests NVMe drives, controller cards, and PCIe cabling.

PCI device status

hwdiag pci status all

PCI target link status and negotiation for all devices.

Fan control & test

hwdiag fan test all

Tests fan tachometers, PWM regulation, and kill circuits.

CPLD / FPGA status

hwdiag cpld spi_global_reg

Reads global SPI/CPLD registers and board control flags.

System LED test

hwdiag led test all

Toggles and verifies status/fault LEDs across the chassis.

Fabric & I²C Subsystem

Run from the diagnostic shell (diag>) to validate bus links, sideband busses, and multiplexers.

Fabric test (All links)

hwdiag system fabric test all

Validates UPI/QPI interconnects, PCIe bus speeds, and memory bus freq.

Fabric test (Specific CPU)

hwdiag system fabric test cpu0

Targets UPI/QPI point-to-point links for a single processor socket.

I²C connectivity test (All)

hwdiag i2c test all

Executes Pass/Fail communication test across all sideband I²C buses.

I²C connectivity test (Specific bus)

hwdiag i2c test <bus#>

Tests a specific bus channel (e.g. hwdiag i2c test 0 or 1).

Scan I²C devices (All buses)

hwdiag i2c scan all

Scans and outputs all responsive I²C addresses behind muxes.

Scan I²C devices (Specific bus)

hwdiag i2c scan <bus#>

Discovers devices responding on a specific I²C target segment.

Power & service control

These commands affect availability. Confirm the correct host and approval first.

Power on host

start /SYS

Starts the host and operating system.

Graceful host shutdown

stop /SYS

Shuts down the OS and powers off the host.

Force host shutdown

stop /SYS -f

Use only when normal shutdown is unresponsive.

Restart host

reset /SYS

Immediately restarts the host.

Cold / deep power cycle

stop /SYS -f

Wait for show /SYS power_state = Off, then run start /SYS.

Restart service processor

reset /SP

Restarts ILOM/SP and disconnects the session.

Locator LED on

set /SYS/LOCATE value=Fast_blink

Turns on front and rear locator LEDs.

Locator LED off

set /SYS/LOCATE value=off

Turns off locator LEDs.

Full diagnostic snapshot

A full snapshot can reboot the host. Obtain approval when allocated.

Set full dataset

ssh -l <guid> <ilom-ip> set /SP/diag/snapshot dataset=full

Includes all available outputs and logs.

Generate snapshot archive

ssh -l <guid> <ilom-ip> set -script /SP/diag/snapshot dump_uri=console > <serial>.zip

Wait up to 10 minutes for the archive.

Verify snapshot

ssh -l <guid> <ilom-ip> show /SP/diag/snapshot

Checks snapshot status.

Return to normal dataset

ssh -l <guid> <ilom-ip> set /SP/diag/snapshot dataset=normal

Run after collection is complete.
